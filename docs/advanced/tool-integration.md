# 工具集成

## 学习目标

了解如何把 Claude 集成到你的工具链中。

## Claude + VS Code

可以配合使用：
- 官方的 Claude VS Code 扩展
- Cursor（内置 Claude 的编辑器）
- 其他 AI 编码助手

## Claude + Git

- 让 Claude 帮你写 commit message
- 让 Claude 审查 PR diff
- 让 Claude 帮你理解代码变更历史

## Claude + CI/CD

虽然 Claude 直接参与 CI/CD 较少见，但可以：
- 让 Claude 审查失败的测试日志
- 让 Claude 帮你理解构建错误
- 让 Claude 写测试用例

## Claude + 项目管理工具

- 让 Claude 帮你写 ticket 描述
- 让 Claude 帮你估算任务
- 让 Claude 帮你总结会议记录

## 注意事项

- 总是审查 Claude 的输出
- 注意不要泄露敏感信息
- 了解各种工具的限制

## 练习

思考一下你的工作流中哪些地方可以引入 Claude？
