# 任务分解

## 学习目标

学习如何把复杂任务分解成 Claude 可以处理的小步骤。

## 为什么分解？

Claude 在处理清晰、定义明确的小任务时表现最佳。复杂任务往往容易出错或遗漏细节。

## 分解策略

### 1. 自顶向下分解

从大目标开始，逐步细化：
1. 我们要做什么？
2. 需要哪些主要部分？
3. 每个部分有哪些步骤？
4. 每个步骤具体要做什么？

### 2. 按阶段分解

软件开发生命周期：
1. 需求分析
2. 方案设计
3. 实现
4. 测试
5. 部署

### 3. 按功能模块分解

- 用户认证
- 数据管理
- UI 组件
- 工具函数

## 示例：构建一个博客

不要：
> "帮我做一个博客系统"

要这样分解：

1. "帮我设计博客系统的数据结构"
2. "基于这个数据结构，创建数据库 schema"
3. "实现博客文章的 CRUD API"
4. "创建博客列表页面"
5. "创建文章详情页面"
6. ...

## 练习

选择一个你想做的项目，练习把它分解成小任务。
