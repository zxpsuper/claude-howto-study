# 提示词工程

## 学习目标

了解提示词工程的高级技术。

## 思维链 (Chain-of-Thought)

让 Claude 展示它的思考过程：

> "请一步一步地思考解决这个问题，然后给出答案。"

## 少样本学习 (Few-Shot Learning)

给 Claude 几个例子，让它学习模式：

```markdown
任务：把描述转换成 emoji

示例：
"开心" → 😊
"难过" → 😢
"惊讶" → 😲

现在转换："庆祝"
```

## 自我一致性

让 Claude 多次回答同一个问题，然后选择最一致的答案。

## 角色提示

给 Claude 一个具体的身份可以显著改变输出：

- "你是一名 Stack Overflow 的资深回答者"
- "你是一名耐心的编程导师"
- "你是一名严谨的代码审计员"

## 提示词迭代

提示词很少一次完美。迭代改进：
1. 写初始提示词
2. 测试并观察问题
3. 调整提示词
4. 重复

## 练习

找一个 Claude 回答不太好的问题，尝试用这些技术改进提示词。
