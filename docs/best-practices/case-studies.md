# 案例分析

## 学习目标

通过真实案例学习如何有效地使用 Claude。

## 案例 1：重构遗留代码库

**挑战**：一个有 5 年历史的 JavaScript 项目，缺乏测试，代码难以理解。

**如何使用 Claude**：
1. 让 Claude 一次分析 1-2 个文件
2. 让 Claude 为代码写注释
3. 让 Claude 解释代码的作用
4. 让 Claude 提出重构建议
5. 小步重构，每次让 Claude 审查

**结果**：成功地把关键模块迁移到 TypeScript，添加了测试。

## 案例 2：学习新技术

**挑战**：团队需要从 Vue 2 迁移到 Vue 3，很多人不熟悉 Composition API。

**如何使用 Claude**：
1. 让 Claude 解释新旧 API 的区别
2. 让 Claude 把 Vue 2 组件的例子转换成 Vue 3
3. 让 Claude 写一个迁移指南
4. 让 Claude 审查团队成员写的第一个 Vue 3 组件

**结果**：团队的学习曲线变得平缓多了。

## 案例 3：Code Review 助手

**挑战**：小团队，没有足够的人力做全面的 code review。

**如何使用 Claude**：
1. PR 先让 Claude 审查
2. Claude 做第一轮检查：
   - 明显的 bug
   - 代码风格问题
   - 安全问题
3. 人类审查者专注于高层次的设计问题

**结果**：code review 质量提高，人类时间花在更有价值的地方。

## 案例 4：入门新项目

**挑战**：加入一个新团队，项目很大，文档很少。

**如何使用 Claude**：
1. 让 Claude 解释项目结构
2. 让 Claude 解释关键文件的作用
3. 让 Claude 生成一个架构图描述（用 Mermaid）
4. 让 Claude 写一个新手指南

**结果**：上手时间大大缩短。
