# 高效工作流

## 学习目标

学习其他人如何高效使用 Claude 的工作流。

## 开发者日常工作流

### 1. 问题理解阶段

1. 把问题丢给 Claude
2. 让 Claude 用自己的话复述问题
3. 澄清任何误解

### 2. 方案探索阶段

1. 让 Claude 提出几个方案
2. 讨论每个方案的优缺点
3. 选择一个方案

### 3. 实现阶段

1. 让 Claude 写初始代码
2. 自己审查和测试
3. 给 Claude 反馈并迭代

### 4. 完善阶段

1. 让 Claude 添加测试
2. 让 Claude 写文档
3. 让 Claude 审查最终代码

## 配对编程模式

想象 Claude 是你的编程搭档：
- 你说想法，Claude 写代码
- Claude 写代码，你审查
- 互相提问，共同思考
- 切换角色，互相评审

## 文档驱动开发

1. 先让 Claude 写文档
2. 确认文档描述了正确的行为
3. 根据文档实现代码
4. 让 Claude 确保代码与文档一致

## 练习

尝试采用其中一个工作流来完成你手头的任务！
