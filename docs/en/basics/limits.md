# Understanding Claude's Limits

## Learning Objectives

Understand what Claude can and cannot do, and how to use it safely.

## What Claude Excels At

✅ **Code-related**
- Explain code logic
- Write new code
- Code review and refactoring suggestions
- Algorithm discussions

✅ **Content Creation**
- Write documentation
- Technical blogs
- Emails and messages

✅ **Learning Assistance**
- Explain concepts
- Provide examples
- Summarize articles

✅ **Problem Analysis**
- Bug analysis
- Architecture discussions
- Approach comparisons

## Important Limitations

⚠️ **Knowledge has cutoff dates**
- Claude's knowledge has cutoff dates
- May not understand the latest technologies
- Verify important information

⚠️ **Code needs verification**
- Generated code may have bugs
- Always test it yourself
- Pay attention to security issues

⚠️ **May fabricate information**
- Occasionally "hallucinates"
- Will make things up when uncertain
- Verify critical information

⚠️ **Context has limits**
- Very long content may be truncated
- Pay attention to conversation length

## Safety Best Practices

1. **Don't share sensitive information** - Don't paste keys, passwords, etc.
2. **Verify important content** - For critical information, confirm from multiple sources
3. **Code security review** - Carefully inspect generated code before use
4. **Maintain human judgment** - Claude is an assistant tool; final decisions are yours

## Exercises

1. Think of a question you think Claude might not answer well
2. If Claude's answer seems wrong, how would you verify it?
