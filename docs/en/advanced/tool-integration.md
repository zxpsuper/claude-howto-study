# Tool Integration

## Learning Objectives

Understand how to integrate Claude into your toolchain.

## Claude + VS Code

Can be used together with:
- Official Claude VS Code extension
- Cursor (editor with Claude built-in)
- Other AI coding assistants

## Claude + Git

- Have Claude help you write commit messages
- Have Claude review PR diffs
- Have Claude help you understand code change history

## Claude + CI/CD

While it's less common for Claude to directly participate in CI/CD, you can:
- Have Claude review failed test logs
- Have Claude help you understand build errors
- Have Claude write test cases

## Claude + Project Management Tools

- Have Claude help you write ticket descriptions
- Have Claude help you estimate tasks
- Have Claude help you summarize meeting notes

## Notes

- Always review Claude's output
- Be careful not to leak sensitive information
- Understand the limitations of various tools

## Practice

Think about where in your workflow you could introduce Claude?
