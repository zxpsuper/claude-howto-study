# Multi-turn Optimization

## Learning Objectives

Learn how to optimize multi-turn conversations to make them more efficient and productive.

## Stay Focused

In multi-turn conversations, it's easy to get off topic. Remember:
- Each interaction should have a clear purpose
- If direction is wrong, correct it promptly
- Complete one subtask before moving to the next

## Effective Feedback Loops

Don't just accept Claude's output—think critically:

> "There's a problem with your solution, it will fail in scenario X. Can you adjust it?"

Or:

> "This implementation is good, but I think part Y can be optimized. Do you have any ideas?"

## Progressive Building

For complex tasks, you can build progressively:

1. First have Claude write a basic version
2. Test and identify issues
3. Have Claude improve based on feedback
4. Repeat until satisfied

## The Art of Follow-up Questions

Don't be afraid to ask follow-up questions:

- "Can you give a specific example?"
- "Why choose this method instead of another?"
- "What potential issues are there with this approach?"
- "What if the situation becomes X?"

## Practice

Choose a programming task you're working on and try using multi-turn conversations to have Claude help you complete it.
