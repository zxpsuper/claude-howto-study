# Claude Code Intro

## Learning Objectives

Understand what Claude Code is and how to use it.

## What is Claude Code?

Claude Code is Anthropic's official command-line tool, designed specifically for developers.

## Installation

```bash
npm install -g @anthropic-ai/claude-code
```

## Basic Usage

Start Claude Code:
```bash
claude
```

## Key Features

- **Direct local file access** - Claude can read and edit your project files
- **Understands project context** - Claude knows the entire project structure
- **Execute commands** - Can run builds, tests, and other commands
- **Git integration** - Understands git status and can help you commit code

## Typical Workflow

1. Start `claude` in your project directory
2. Tell Claude what you want to do
3. Claude looks at relevant files
4. Claude makes changes
5. You review and approve

## Safety Tips

- Be aware Claude may execute commands
- Review all code changes
- Don't use in sensitive directories
