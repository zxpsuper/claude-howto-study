# Case Studies

## Learning Objectives

Learn how to effectively use Claude through real cases.

## Case 1: Refactoring Legacy Codebase

**Challenge**: A 5-year-old JavaScript project with no tests and hard-to-understand code.

**How Claude was used**:
1. Have Claude analyze 1-2 files at a time
2. Have Claude write comments for the code
3. Have Claude explain what the code does
4. Have Claude propose refactoring suggestions
5. Refactor in small steps, having Claude review each time

**Result**: Successfully migrated key modules to TypeScript and added tests.

## Case 2: Learning New Technology

**Challenge**: Team needed to migrate from Vue 2 to Vue 3, many not familiar with Composition API.

**How Claude was used**:
1. Have Claude explain differences between old and new APIs
2. Have Claude convert Vue 2 component examples to Vue 3
3. Have Claude write a migration guide
4. Have Claude review team members' first Vue 3 components

**Result**: Team's learning curve became much gentler.

## Case 3: Code Review Assistant

**Challenge**: Small team, not enough manpower for comprehensive code review.

**How Claude was used**:
1. PR first reviewed by Claude
2. Claude does first round checks:
   - Obvious bugs
   - Code style issues
   - Security issues
3. Human reviewers focus on high-level design issues

**Result**: Code review quality improved, human time spent on more valuable areas.

## Case 4: Onboarding to New Project

**Challenge**: Joining a new team with a large project and little documentation.

**How Claude was used**:
1. Have Claude explain project structure
2. Have Claude explain what key files do
3. Have Claude generate an architecture diagram description (using Mermaid)
4. Have Claude write a beginner's guide

**Result**: Onboarding time greatly reduced.
