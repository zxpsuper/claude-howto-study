# 上下文管理

## 学习目标

学习如何有效地管理对话上下文，以获得更好的结果。

## 上下文窗口

Claude 有一个上下文窗口限制——这意味着它只能记住对话中最近的一定数量的 token。

## 管理上下文的技巧

### 1. 关键信息摘要

当对话变长时，要求 Claude 做一个摘要：

> "请把我们刚才讨论的关键点整理成一个简洁的摘要，方便后续参考。"

### 2. 分阶段处理

不要试图在一个对话中完成所有事情。把大任务分成多个对话：
- 对话 1：需求分析
- 对话 2：方案设计
- 对话 3：代码实现
- 对话 4：审查优化

### 3. 使用外部文档

对于非常大的代码库或文档，可以考虑：
- 只粘贴相关的部分
- 使用 Claude Code 的文件引用功能
- 使用 Claude API 进行批量处理

### 4. 定期重置

当发现 Claude 开始忘记早期内容时，可以开始一个新的对话，并把必要的上下文粘贴进去。

## 示例工作流

```
对话 1：
- 讨论项目需求
- 获取 Claude 的建议
- 记录关键决策

对话 2：
- 粘贴关键决策作为上下文
- 开始实现功能 A
- ...
```

## 练习

回顾你最近的一次长对话，想想要是重新开始，你会如何更好地管理上下文？
